# Features

The pages below follow the visual editor's overview: the calendars a card reads, what the whole
card shares, and its four layouts. Each section names the editor pages it documents, so you can
read about a setting where the editor puts it.

## 🗂️ Calendars

The editor's **Calendars** rows, a page for each calendar entry.

| Page                                                | What it covers                                                                                |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [Calendars](/features/core-settings)                | Names, colors, labels and pictures, visibility conditions, private calendars, text size       |
| [Calendar Lanes](/features/lanes)                   | A fixed place in every grid day for each calendar or person                                   |
| [Filtering & Text Replacement](/features/filtering) | Which of a calendar's events show, by text, type, weekday or hour; duplicates; rewriting text |

## 🧩 Whole Card

The editor's **Whole Card** pages: **Card & Header**, **Events, Weather & Language** and
**Taps & Refresh**.

| Page                                        | What it covers                                                                   |
| ------------------------------------------- | -------------------------------------------------------------------------------- |
| [Visual Editor](/features/editor)           | The editor itself: its overview, Quick Setup, search, Undo and Pick From Preview |
| [Header Toolbar](/features/header-toolbar)  | Paging, the view switcher, the calendar filter, search and your own buttons      |
| [Dynamic Titles](/features/title-templates) | A title that changes with Home Assistant's state                                 |
| [Actions & Interactions](/features/actions) | Taps and holds, the event popover, adding, editing, moving and deleting events   |
| [Weather Integration](/features/weather)    | The forecast beside days and events, set per layout                              |

## 🗺️ Layouts

The editor's **Layouts** rows and their topics: **Which Events**, **Days**, **Event Appearance**,
**Size & Spacing** and **Weather**.

| Page                                                 | What it covers                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------------------ |
| [Choose a Layout](/features/layouts)                 | The four layouts and how each one's block shares options with the others       |
| [List View](/features/list-view)                     | The default layout, compact mode, event limits and event order                 |
| [Column View](/features/column-view)                 | Days side by side, and how a narrow card sheds columns                         |
| [Grid View](/features/grid-view)                     | Days on a time axis: hours, all-day events, overlaps and dragging              |
| [Month View](/features/month-view)                   | Six weeks at a glance, and the narrow month on a phone                         |
| [Event Content & Display](/features/event-content)   | What each event shows: times, locations, countdowns, badges, past events       |
| [Split Multi-Day Events](/features/multi-day-events) | Events that run over several days                                              |
| [Dynamic Start Date](/features/start-date-offset)    | Starting the card on another day than today                                    |
| [Layout & Appearance](/features/layout-appearance)   | Height, colors, spacing, the date column, week numbers and the today indicator |
